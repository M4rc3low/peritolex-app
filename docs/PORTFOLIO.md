# PeritoLex no portfólio

## Resumo curto

PeritoLex é uma aplicação web para organização e análise de informações jurídicas, com foco em produtividade, acompanhamento de processos e controle visual de dados relevantes.

## Problema identificado

Rotinas jurídicas e periciais podem depender de controles manuais, consultas repetitivas e informações espalhadas. Isso dificulta a visão geral dos processos e aumenta o risco de perda de prazos ou falta de priorização.

## Solução proposta

Criar uma interface visual para centralizar informações, destacar prioridades e apoiar a tomada de decisão com dados organizados.

## Diferenciais do projeto

- Aplicação voltada para um problema real
- Interface web moderna
- Possibilidade de evolução para automação e alertas
- Base para dashboards e análise de risco
- Projeto com potencial de uso profissional

## Tecnologias demonstradas

- React
- Vite
- Tailwind CSS
- Componentização
- Organização de rotas
- Visualização de dados
- Documentação técnica
